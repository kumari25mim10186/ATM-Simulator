# 1. Introduction

The ATM Simulator is a console-based banking application developed using the C++ programming language. The project is designed to simulate the working functionality of an Automated Teller Machine (ATM). It provides users with an interactive environment where they can perform banking operations such as checking account balance, depositing money, withdrawing money, transferring funds, and viewing transaction history.

In modern banking systems, ATMs play a very important role in providing quick and secure banking services to users without requiring direct interaction with bank staff. This project aims to replicate the basic working mechanism of an ATM in a simplified software environment.

The project helps students understand programming fundamentals and real-world banking logic implementation using Object-Oriented Programming concepts in C++.

# 2. Problem Statement

The objective of this project is to develop a secure and user-friendly ATM Simulator that performs basic banking operations using C++. The system should provide PIN-based authentication and allow users to carry out different transactions safely and efficiently.

The application should:

* Allow secure user login
* Display account balance
* Support deposit and withdrawal operations
* Maintain transaction history
* Handle invalid inputs and insufficient balance situations

# 7. Functional Requirements

### 3. Deposit Money

# 8. System Design

The system is designed using a menu-driven approach where users interact with different options through the console interface.

The workflow of the system is:

1. User enters PIN
2. System verifies credentials
3. Main menu is displayed
4. User selects desired operation
5. System processes the request
6. Result is displayed
7. User continues or exits

---

# 9. Algorithm

## Step-by-Step Algorithm

1. Start the program
2. Display ATM login screen
3. Ask user to enter PIN
4. Verify entered PIN
5. If PIN is correct:

   * Display ATM menu
6. Else:

   * Show error message
   * Exit system
7. Perform selected operation:

   * Check Balance
   * Deposit
   * Withdraw
   * Transfer
   * Transaction History
8. Repeat until user selects Exit
9. Terminate program
