# ATM-Simulator
📌Overview
The main purpose of this project is to demonstrate how banking systems work internally while applying important programming concepts such as Object-Oriented Programming (OOP), file handling, and data management in C++. The system provides a secure and user-friendly environment where account holders can manage their finances digitally without direct human interaction.

The application allows users to:
Log in using an Account Number and PIN
Check account balance
Deposit money
Withdraw cash
Transfer funds between accounts
Change ATM PIN
View transaction history
Exit securely from the system
