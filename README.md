# ATM-Simulator
# ATM Simulator using C++

## 📌 Project Overview

The ATM Simulator is a console-based banking application developed using C++.
This project simulates the basic functionalities of an Automated Teller Machine (ATM).

The application allows users to:

* Login securely using a PIN
* Check account balance
* Deposit money
* Withdraw money
* Transfer funds
* View transaction history

This project demonstrates the implementation of Object-Oriented Programming (OOP) concepts and banking system logic.
